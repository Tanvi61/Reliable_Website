# Reliable Land Survey Consultancy Website

This is a premium, modern, and visually impressive corporate website built for Reliable Land Survey Consultancy.

## Technology Stack
- HTML5
- CSS3 (Vanilla)
- Vanilla JavaScript

## Project Structure
```text
reliable-land-survey/
│
├── index.html
│
├── css/
│   ├── style.css
│   └── responsive.css
│
├── js/
│   └── script.js
│
├── assets/
│   ├── images/
│   ├── icons/
│   └── logo/
│
└── README.md
```

## Features
- Fully responsive design (Desktop, Tablet, Mobile)
- Semantic HTML5 & SEO friendly structure
- Interactive Hero section with subtle digital survey overlay
- Animated counters for technical manpower and instruments
- Custom interactive Technology showcase section
- Dynamic Testimonial Carousel
- Client-side validation for Enquiry form
- Floating action buttons (WhatsApp, Call)

## Usage
Simply open `index.html` in any modern web browser to view the website. No build step or development server is required.
